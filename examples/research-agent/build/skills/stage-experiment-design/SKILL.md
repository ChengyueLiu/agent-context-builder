# 实验设计

## 质量标准

- 每条论断都有对应的对照组和必要的消融。
- 写明评测指标、数据划分和统计检验方法。
- 写明停止条件：什么结果算支撑、什么算不支撑，在跑实验之前定下。

## 做法

### 目标
把论断清单变成可执行的实验方案，在跑实验之前就定下什么结果算支撑。

### 步骤
1. 论断清单逐条列出需要的证据。
2. 为每条证据设计实验：数据、基线、指标、对照、消融。
3. 写明停止条件和统计检验方法。
4. 估算算力和时间，超出预算的标出来交用户决定。

### 产出
实验方案，交用户拍板后进入实验执行。

## 注意事项

- 不要只在一个数据集上评测：审稿人会质疑泛化性。至少用两个公认的基准。
- 基线用原论文推荐的超参，或者给基线同样的调参预算：否则提升可能只是调参带来的。
- 测试集只在最后用一次：反复看测试集，它就变成了验证集。
