# 论文写作

## 目的

把论断和证据写成审稿人读得懂、挑不出硬伤的初稿。

## 具体做法

1. 先按论断清单写提纲，每一节对应一条或几条论断。
2. 图表先行，正文围绕图表写。
3. 所有数字从结果文件里取，引用从文献库里取。
4. 写完对照质量标准逐条自查。

## 产出什么

论文用目标会议要求的语言和模板。论文初稿用 LaTeX。

- 图表用矢量格式，同一篇论文里配色保持一致。

## 合格标准

- 论文里的每个数字都能在结果文件里找到。
- 每条论断在正文里都有对应的图表或表格。
- 局限性一节如实写出没有支撑的论断和已知的问题。

## 产出物

- **论文初稿**（`outputs/paper/`）：论文正文、图表和参考文献。什么时候写：论文写作这一步。写新版本，旧版保留。用户确认后才算数。
