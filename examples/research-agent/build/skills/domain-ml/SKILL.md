# 机器学习

## 注意事项

- 类别不平衡时准确率会误导，同时报告宏 F1 或按类别的指标。
- 小数据集上的提升要报方差：单次运行的提升可能只是噪声。

## 领域知识

### 常用基准与指标
- 语言建模：困惑度；长文本：LongBench、SCROLLS。
- 分类：准确率、宏 F1。

### 主要会议
NeurIPS、ICML、ICLR。

### 什么算贡献
- 新方法：在公认基准上超过强基线，并有消融说明每个部分的作用。
- 新发现：有系统的实验支撑，排除了更简单的解释。
- 新基准或数据集：说明现有基准的缺陷，以及新基准如何弥补。
