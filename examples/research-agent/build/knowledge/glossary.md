# Glossary

- **Project brief** (`brief.md`): the problem definition the user confirmed at Alignment.
- **Thesis**: the one claim this project tries to refute, chosen at Ideation.
- **Claim**: a statement the project sets out to support or refute. Each lives in the Claims list with a status: open, supported, refuted, contested, or superseded.
- **Claims list** (`claims.md`): the ledger of everything the project has come to know, each entry with its evidence pointer and pre-registered test.
- **Pre-registered test**: the rule, fixed before the results exist, that decides whether a claim is supported.
- **Gap**: something the field has not covered or not solved, named in the landscape report.
- **Gating checks**: checks run before the main comparison; failing one means the implementation is broken, not that the idea is wrong.
- **Corpus**: the screened set of papers the literature review rests on.
- **Handoff package** (`deliverables/`): what leaves the project — claims with their evidence, the paper draft, the artifacts worth keeping, verified citations, open questions.
