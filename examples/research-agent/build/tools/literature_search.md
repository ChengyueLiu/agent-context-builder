# 文献检索（`literature_search`）

检索学术文献，返回元数据和摘要。

## 定义

参数：
- `query`：检索词，用英文效果更好。
- `years`：年份范围，如 `2023-2026`。
- `limit`：返回条数，默认 20。

返回：每篇的标题、作者、年份、会议、摘要、链接。

示例：`{"query": "long-context transformer stability", "years": "2023-2026", "limit": 20}`

## 输出上限

最多返回 50 条；摘要超过 500 字时截断。

## 规程

检索后先把结果存档，再引用。引用只能来自存档的检索结果。
