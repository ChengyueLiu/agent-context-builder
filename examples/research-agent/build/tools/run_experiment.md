# 实验运行（`run_experiment`）

在沙箱中运行一次实验。

## 定义

参数：
- `config`：实验配置文件的路径。
- `seed`：随机种子。

返回：运行 id、状态、结果文件和日志的位置。

示例：`{"config": "configs/ablation-1.yaml", "seed": 42}`

## 输出上限

日志只返回最后 200 行，完整日志在返回的日志位置。

## 规程

1. 跑实验前，先把配置登记到实验记录：代码版本、超参、数据、随机种子。
2. 跑完把结果和日志位置追加到实验记录，不改已有的记录。
3. 失败时先记录失败原因，再决定是否重试。
